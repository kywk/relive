旅程，留在你的筆記

原始 GPX 和照片放在自己的 Vault。用一個 relive 區塊，串起路線、拍攝時刻與沿途故事。

同一份內容可以在 Obsidian 回放，也能經 Docusaurus 發布成網站。你的文字與檔案始終由你保存。

閱讀完整語法
旅程.md
```relive
title: 鴨川散步
gpx: ./ride.gpx
duration: 40
stopDuration: 3
photos:
  - src: ./river.jpg
    time: '2026-10-29T09:10:00+09:00'
    caption: 在河邊停一會兒
```

用照片時間或 GPS 配對軌跡，並保留每個停留片刻。

下載安裝檔

把旅行誌發布成網站

先從 GitHub Release 下載 kywk-relive-0.1.0.tgz，再於網站專案安裝。npm registry 尚未發布。

npm install ./kywk-relive-0.1.0.tgz

使用 @kywk/relive/integration，指定公開附件目錄；建置時可選用 gentle 瘦身，Vault 原檔保持不變。

查看 Docusaurus 設定

讓長軌跡輕一點

下載 kywk-gpx-slim-0.1.0.tgz，以 Node.js 22+ 執行。先比較各種強度，再決定怎麼精簡。

npx --offline --yes \
  --package ./kywk-gpx-slim-0.1.0.tgz \
  gpx-slim ride.gpx --analyze

工具在本機處理 GPX，並拒絕覆寫原檔。

閱讀 CLI 說明

出發前，想知道的事

我的照片會被上傳嗎？

Obsidian 中的本機照片不會由 Relive 自動上傳。發布 Docusaurus 網站時，文章引用的公開附件會進入網站產物，請只允許發布專用的 assetRoots。2D 圖磚連線到 OpenStreetMap；3D 底圖與地形連線到 OpenFreeMap、Mapterhorn。

瘦身會改變照片的位置嗎？

精簡會改變軌跡的內插位置與距離統計。只有 GPS 的照片，在停留或重訪同一位置時也可能改變播放時刻。網站建議明確選用 gentle；需要精確順序時，保留拍攝時間或關閉瘦身。

閱讀實測結果
3D 地圖需要 API key 嗎？

選擇 MapLibre 3D 即可使用開放底圖、立體地形與建築輪廓，不需要 API key。首次切換才載入 3D 引擎；裝置或網路不支援時會回到 2D。這不是寫實攝影城市。Google 寫實 3D 仍是需自備 key 的選配，官方 demo 不啟用。
