# Relive 0.2.2

- 將 MapLibre 6 的 Worker 打包進發行產物，修正網站及 Obsidian 3D 地圖載入逾時。消費端不需另設 Worker URL，也不下載遠端執行程式。
- 延續 0.2.1 的 MapLibre 6.4.1 安全修補；Obsidian 僅提供 Leaflet 2D 與 MapLibre 3D，Google 3D 保留於網站與 React 整合。
- React 套件更新為 0.1.2，依賴修正後的共用播放器。
- 官網安裝分頁改用已發布的 npm 套件，Obsidian 下載連結指向最新附件。

Obsidian 安裝：下載 main.js、manifest.json、styles.css 至 vault 的 .obsidian/plugins/relive/，再重新載入。2026-11-05 已完成 Community 自動審核，可從 [官方目錄](https://community.obsidian.md/plugins/relive) 安裝。附件簽章、依賴安全及原始碼逐位元組重建比對通過；仍有非阻擋的文件、樣式與網域組字掃描提醒。

已發布 npm：`@kywk/relive@0.2.2`、`@kywk/react-relive@0.1.2`、`@kywk/gpx-slim@0.1.0`。47 項測試、網站建置、3D 瀏覽器實測與 registry 消費端安裝驗證通過。
