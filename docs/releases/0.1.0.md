# Relive 0.1.0

首版 GitHub 發行，包含 Obsidian 旅程回放、Docusaurus 整合及獨立 GPX 瘦身 CLI。

## 功能

- Obsidian 與 Docusaurus 共用 `relive` Markdown 區塊，支援 GPX、照片時間／GPS 配對、時間軸、事件停留與 Leaflet 地圖回放。
- Docusaurus build 可設定 GPX 瘦身強度及目標刪點比例；原始 Vault GPX 與 Obsidian 載入流程不變。網站建議明確設定 `gpxSlim: {preset: 'gentle'}`。
- `@kywk/gpx-slim` 提供三種壓縮強度、分析預覽、目標刪點比例與拒絕覆寫保護，可由 tarball 離線 npx 執行。
- 附帶 2 萬／10 萬點的 30 輪 Chromium 效能測試結果與重跑腳本。

## 下載與安裝

- Obsidian：將 `main.js`、`manifest.json`、`styles.css` 放入 `<vault>/.obsidian/plugins/relive/`，重新載入並啟用。
- Docusaurus：下載 `kywk-relive-0.1.0.tgz` 後執行 `npm install ./kywk-relive-0.1.0.tgz`，整合入口是 `@kywk/relive/integration`。
- GPX Slim：下載 `kywk-gpx-slim-0.1.0.tgz` 後執行 `npx --offline --yes --package ./kywk-gpx-slim-0.1.0.tgz gpx-slim ride.gpx --analyze`。
- `SHA256SUMS` 可用 `sha256sum -c SHA256SUMS` 驗證；macOS 可用 `shasum -a 256 -c SHA256SUMS`。附件附 GitHub artifact attestations。

## 發布狀態與限制

本次只發布 GitHub 附件，尚未發布 npm registry，也尚未提交／上架 Obsidian Community。後續 npm 發布分別使用 `npm-v*` 與 `gpx-slim-v*` tag，需先完成 npm Trusted Publisher 設定。

瘦身會影響位置內插、距離統計與純 GPS 照片的配對時刻；停留／折返場景需要精確順序時，可關閉瘦身或提供照片拍攝時間。效能結果使用合成軌跡與桌面 Chromium，不代表手機或所有真實旅程。Google 3D 為選配功能，尚未使用真實 API key 完成驗證。

詳見 repository README、GPX Slim README 與 `docs/gpx-slim-performance.md`。
