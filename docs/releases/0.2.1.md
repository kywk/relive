# Relive 0.2.1

修正 Obsidian Community 自動審核指出的遠端 JavaScript 載入問題。

- Obsidian 安裝包在建置時排除 Google Maps 遠端程式載入器，移除其設定入口；保留 Leaflet 2D 與已打包的 MapLibre 3D。
- 筆記指定 Google 3D 時顯示清楚提示並回到 2D。網站／React 整合仍可選用 Google 3D。
- MapLibre 升級至 6.4.1，修補 GHSA-jrc7-96c5-q579；React 套件更新為 0.1.1，依賴修補後的共用播放器。
- README 補上英文介紹、網路服務與隱私說明。

下載 main.js、manifest.json、styles.css 至 vault 的 .obsidian/plugins/relive/ 後重新載入。Community 是否可安裝仍以自動審核結果為準。原始 GPX 與照片不變；不覆寫已發布版本。
