# Relive 0.2.0

本版更新 Obsidian 與網站共用播放器，並提供首個獨立 React 套件。

## 更新

- 新增免金鑰 MapLibre 3D 地形／建築回放，保留 Leaflet 2D 與選配 Google 3D。
- `@kywk/react-relive@0.1.0` 提供 React 19 元件、SSR 安全載入、TypeScript 宣告與樣式入口，重用 `@kywk/relive@0.2.0` 播放器。
- GPS 照片配對減少不必要的距離計算，保留時間優先與同距離取首點。合成基準 CPU 時間降低約 57%，不代表整體 FPS。
- 官網延後載入旅程與播放器，改善手機首屏資產量；新增獨立 Vite React 範例。
- 隨附 `@kywk/gpx-slim@0.1.0` CLI，可分析並精簡分享用 GPX，原始檔不覆寫。

## 安裝

Obsidian：下載 `main.js`、`manifest.json`、`styles.css`，放入 `<vault>/.obsidian/plugins/relive/` 後重新載入外掛。

網站：`@kywk/relive@0.2.0`；React：`@kywk/react-relive@0.1.0`；CLI：`@kywk/gpx-slim@0.1.0`。npm 上架與 Obsidian Community 審核獨立進行，GitHub 附件存在不等於社群目錄已通過。

附件中的 `SHA256SUMS` 可用 `shasum -a 256 -c SHA256SUMS` 核對。React 首次使用本機 tarball 時，需同時安裝共用套件與 React 套件。

## 限制

地圖圖磚與 3D 需要網路；Google 3D 需要使用者自己的 key 與帳務，尚未以真實 key 完整驗證。不提供影片匯出、音樂或離線地圖。示範軌跡為合成資料；分享前請自行確認 GPX 與照片可公開。
